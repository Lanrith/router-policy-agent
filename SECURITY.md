# Security

Report vulnerabilities through [GitHub private vulnerability reporting](https://github.com/Lanrith/router-policy-agent/security/advisories/new). Do not include credentials, packet captures or deployment configuration in public issues.

Use signed release provenance and reviewed source/workflow commits when admitting packages. Component tests qualify the documented component boundary; deployment owners must qualify their service, network and state integrations. A published signature does not certify every installation.
